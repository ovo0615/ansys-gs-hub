# ANSYS Getting-Started Hub 操作說明

此工具由虎門科技資深技術工程師 Jeff Hong 洪敬傑提供。

本文件寫給**第一次使用的人**，假設你完全沒碰過 PyAnsys，也不熟悉 HFSS／Mechanical／Fluent 的操作介面。

---

## 一、開始之前要準備什麼

### 1．一定要有的

| 項目 | 說明 |
| --- | --- |
| Windows 10 或 11（64 位元） | 本工具只支援 Windows |
| 網路連線 | **只有第一次啟動需要**，用來下載 Python 套件 |

### 2．不用自己準備的

- **Python**：如果你的電腦沒有相容版本（3.10／3.11／3.12），啟動腳本會用 WinGet 以「使用者層級」
  幫你安裝 Python 3.12。它**不會移除、也不會降級**你電腦上任何既有的 Python 版本。
- **Node.js**：完全不需要。發布內容已經包含建置好的網頁前端。
- **Python 套件**：啟動腳本會自動在 `backend\.venv` 建立一個**專屬的虛擬環境**再安裝，
  不會影響你電腦上其他 Python 專案。

### 3．要自己安裝並持有授權的 ANSYS 商業軟體

本工具**不含任何 ANSYS 元件**，只是去呼叫你電腦上已經安裝好的 ANSYS。
你想用哪個領域，就要有對應的軟體與有效授權：

| 你想用的分頁 | 需要的軟體 | 本專案實測版本 |
| --- | --- | --- |
| HFSS · 偶極天線 | ANSYS Electronics Desktop（含 HFSS） | 2026 R1 |
| Mechanical · 懸臂樑 | ANSYS Mechanical | 2026 R1 |
| Fluent · 混合三通 | ANSYS Fluent | 2025 R2 |

> 沒有安裝也可以先玩：每個分頁都有**理論估算**，可以完整操作介面、看參數怎麼影響結果，
> 只是按下「開始求解」時會顯示找不到求解器的錯誤訊息。

## 二、安裝步驟

### 步驟 1：下載

在 GitHub 專案首頁按綠色的 **Code** 按鈕 → **Download ZIP**。
（或到 **Releases** 頁面下載版本化的 ZIP。）

### 步驟 2：解壓縮

把下載的 ZIP **完整解壓縮**到一個資料夾，建議路徑短、不含特殊字元，例如：

```
D:\ansys-gs-hub
```

> ⚠️ **最常見的失敗原因**：直接在壓縮檔裡面按 `start.bat`。
> Windows 的壓縮檔預覽是唯讀暫存區，腳本無法在裡面建立虛擬環境，一定會失敗。
> 請務必先「解壓縮全部」。

### 步驟 3：執行

連按兩下資料夾裡的 **`start.bat`**。

會跳出一個黑色（或藍色）的命令視窗，依序顯示：

```
[1/5] 檢查發布內容...
[2/5] 尋找相容的 64 位元 Python（支援 3.12 / 3.11 / 3.10）...
[3/5] 準備獨立虛擬環境 backend\.venv...
[4/5] 依 requirements.lock.txt 安裝後端套件（第一次執行需要網路，可能數分鐘）...
[5/5] 啟動服務：http://127.0.0.1:8017
```

**第一次執行**會停在 [4/5] 一段時間（下載安裝套件，約數分鐘），請耐心等候。
**第二次以後**只要幾秒鐘。

服務就緒後會**自動打開瀏覽器**。如果沒自動開，手動輸入網址：<http://127.0.0.1:8017>

## 三、介面總覽

畫面分成四塊：

| 區域 | 內容 |
| --- | --- |
| **上方分頁** | 切換 HFSS／Mechanical／Fluent 三個領域 |
| **左欄** | 參數輸入、輸出資料夾選擇、「開始求解」按鈕 |
| **中間上方** | 即時 3D 幾何預覽（拖曳旋轉、滾輪縮放）。求解完成後右半邊會並排顯示結果圖 |
| **下方** | 求解日誌（即時串流）＋ 結果數值與圖表 |

三個分頁的操作邏輯完全一致：

```
左側調參數 → 中間看 3D 預覽即時變化 → 按「開始求解」→ 下方看日誌 → 完成後看結果
```

各區塊之間的分隔線都可以**拖曳調整大小**。上方「檢視」選單可以隱藏／顯示系統日誌。

## 四、HFSS · 偶極天線

### 操作步驟

1. 切到「**HFSS · 偶極天線**」分頁。
2. 調整左側參數：

   | 參數 | 說明 | 預設 |
   | --- | --- | --- |
   | 中心頻率 | 想讓天線共振的頻率 | 2.4 GHz |
   | 導線半徑 | 兩段圓柱導線的半徑 | 0.5 mm |
   | 饋入間隙 | 中央饋入埠的間隙高度 | 1.0 mm |
   | 天線總長度 | **留空會自動依頻率估算**（約 0.48 λ） | 自動 |
   | 掃頻範圍 | 以中心頻率的百分比表示 | 40 % |

3. **注意介面的防呆提示**：如果總長度與中心頻率不匹配，會出現黃色警告，說明這是
   「電性短／長天線」造成的阻抗失配（而不是饋入埠設錯），並提供一鍵設為共振長度的按鈕。
4. 選擇模擬檔案的輸出資料夾（可按「瀏覽…」挑，或按「驗證／建立」確認路徑可用）。
5. 按「**開始模擬**」。後端會啟動或連接本機 AEDT，建立幾何 → 饋入埠 → 輻射邊界 → 求解設定 →
   掃頻 → 求解。過程可能需要數分鐘，日誌會即時顯示進度。

### 怎麼確認結果是對的

求解完成後會顯示兩張圖：

- **S11 掃頻曲線**（右下）：共振點是曲線的最低點。2.4 GHz 的半波長偶極，共振頻率應該落在
  **2.2～2.5 GHz**，−10 dB 頻寬約數百 MHz。
- **遠場輻射方向圖**（3D 預覽右側，極座標圖）：
  - 峰值增益應約 **2～2.2 dBi**
  - 峰值出現在 **Theta = 90°**（天線側向）
  - **Theta = 0° 與 180°**（天線軸向，圖的正上方與正下方）應該是深零點

  這就是偶極天線典型的「甜甜圈」方向圖剖面。如果圖形不是這樣，通常代表天線長度與頻率不匹配。

## 五、Mechanical · 懸臂樑

### 操作步驟

1. 切到「**Mechanical · 懸臂樑靜態結構**」分頁。
2. 設定樑的長度、寬度、高度、材料（結構鋼／鋁合金／鈦合金）、自由端的集中力。
3. 左側會即時顯示**理論估算**：最大彎曲應力 σ = FLc/I、自由端變形 δ = FL³/3EI、安全係數、質量。
4. 按「**開始求解**」。

### 怎麼確認結果是對的

把求解結果和左側的理論估算**對照**：

| 項目 | 對照方式 |
| --- | --- |
| von Mises 最大應力 | 應接近理論的 σ = FLc/I（懸臂樑固定端表面） |
| 總變形 | 應接近理論的 δ = FL³/3EI |
| 應力雲圖 | 最大應力應出現在**固定端**，自由端應力接近零 |

例：長 200 mm × 寬 20 mm × 高 20 mm 的結構鋼樑、自由端受 100 N，
理論值為 σ ≈ 50 MPa、δ ≈ 0.333 mm、安全係數 ≈ 5.0。

## 六、Fluent · 混合三通

### 操作步驟

1. 切到「**Fluent · 混合三通**」分頁。
2. 設定管半徑、管臂長度，以及**冷側**與**熱側**各自的流速與溫度。
3. 左側會即時顯示**理論估算**：質量守恆（ṁ = ρVA）加能量守恆算出的混合溫度、出口流速、
   雷諾數與流態（層流／過渡／紊流）。
4. 按「**開始求解**」。後端會依序執行：
   - PyAnsys Geometry 建立 T 形幾何並逐面三角化輸出 STL
   - PyPrimeMesh 產生體網格
   - Fluent solver 求解（開啟能量方程 + k-ε 紊流模型）

   這是三個領域裡最花時間的，請耐心等候。

### 怎麼確認結果是對的

- **出口混合溫度**應介於冷側與熱側溫度之間，並偏向質量流率較大的那一側。
- **溫度雲圖**應該看得出冷熱兩股在 T 形接合處混合、往出口方向趨於均勻。

> ⚠️ **已知限制（誠實說明）**：目前預設疊代次數下，出口溫度尚未完全收斂
> （150 步得到 34.78 °C，理論值 43 °C，方向正確但還在靠近中）；
> **出口流速數值目前不合理**（實測 10723 m/s，理論約 8 m/s），成因是網格偏粗加上收斂不足，
> 屬 CFD 調校問題。溫度場相對穩定可參考，速度值請暫時不要直接引用。

## 七、結束與清理

- **結束服務**：在啟動的命令視窗按 **Ctrl+C**，或直接關閉該視窗。
  服務是前景程序，視窗關掉就一併結束，不會留下背景程序佔用連接埠。
- **模擬產出**存放在你指定的輸出資料夾（預設 `backend\projects`），包含 `.aedt`／`.mechdat`／
  `.cas.h5` 等專案檔與雲圖。這些檔案**不會**被上傳到任何地方，要刪除直接刪資料夾即可。
- **完整移除本工具**：直接刪掉整個解壓縮出來的資料夾即可。
  Python 套件全裝在資料夾內的 `backend\.venv`，不會殘留在系統裡。
  （若當初是由腳本用 WinGet 幫你裝的 Python，那個 Python 會保留在系統中，可自行從
  「設定 → 應用程式」移除。）

## 八、疑難排解

| 症狀 | 原因與解法 |
| --- | --- |
| 按 `start.bat` 視窗一閃就關 | 十之八九是**沒有解壓縮**就直接在 ZIP 裡執行。請先完整解壓縮。 |
| 顯示「找不到已建置的前端」 | 資料夾不完整。請重新下載並完整解壓縮，不要只複製部分檔案。 |
| 服務起來了但瀏覽器沒自動開 | 看命令視窗最後一行：成功會顯示綠色「服務已就緒，已開啟瀏覽器」；失敗會顯示紅色訊息並**把網址印出來**，複製到瀏覽器即可（<http://127.0.0.1:8017>）。舊版曾因用 `Start-Job` 開瀏覽器被防毒軟體（實測 WithSecure）判定為 `Trojan:AMSI/SuspiciousExecute.A` 攔截而無聲失敗，現版本已改寫。 |
| 顯示「連接埠 8017 已被佔用」 | 訊息會列出佔用者的程序名稱與 PID。請自行確認後關閉該程序——腳本**刻意不會**自動終止未知程序。最常見是上一次服務沒關乾淨。 |
| 找不到 Python 且 WinGet 被封鎖 | 手動安裝 64 位元 Python 3.10／3.11／3.12（<https://www.python.org/downloads/windows/>），安裝時勾選「Add python.exe to PATH」，再重新執行。 |
| 套件安裝失敗 | 多半是公司 Proxy／防火牆擋住 PyPI。請洽 IT 取得 Proxy 設定。 |
| 求解時顯示找不到 ANSYS | 本工具不含 ANSYS 本體，請確認對應商業軟體已安裝且授權有效。 |
| 網頁打得開但按求解沒反應 | 檢查下方求解日誌是否有紅色錯誤訊息；WebSocket 連線失敗時會明確提示。 |

## 九、隱私說明

- 服務只綁定 **127.0.0.1**（本機迴路位址），**同網段的其他電腦連不進來**。
- 幾何、網格、求解、後處理**全部在你自己的電腦上執行**，不會上傳任何資料到外部。
- 唯一需要網路的時機，是第一次啟動時從 PyPI 下載 Python 套件。
